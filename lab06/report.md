# Звіт до лабораторної роботи №06

**Тема:** Циклічно-розгалужені алгоритми  
**Виконав:** Шумило Назар  
**Група:** 21КІ  
**Варіант:** 11

## Мета
Навчитися використовувати цикл `for`, розгалуження та лічильники для обробки набору даних.

## Умова варіанта
Для варіанта 11 задано межі `L = -25 °C`, `H = -5 °C`. Потрібно підрахувати:
- `below` — кількість температур `t < -25`;
- `inside` — кількість температур `-25 ≤ t ≤ -5`;
- `above` — кількість температур `t > -5`.

Кількість показів `n` має бути від 1 до 30, кожна температура — від -100 до 100 °C.

## Алгоритм
1. Зчитати `n` і перевірити його межі.
2. Ініціалізувати три лічильники нулями.
3. У циклі зчитати кожну температуру та перевірити її межі.
4. За допомогою `if / else if / else` збільшити відповідний лічильник.
5. Вивести три результати.

## Ручне трасування
Для тесту `5 -30 -25 -15 -5 0`:
- -30 < -25: `below = 1`;
- -25 і -15 належать [-25; -5]: `inside = 2`;
- -5 належить межам інтервалу, тому `inside = 3`;
- 0 > -5: `above = 1`.

Очікуваний результат: `below = 1`, `inside = 3`, `above = 1`.
