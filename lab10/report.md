# Звіт до лабораторної роботи №10

**Тема:** Робота з одновимірними масивами  
**Виконав:** Шумило Назар  
**Група:** 21КІ  
**Варіант:** 11

## Мета
Навчитися зберігати послідовність у масиві та знаходити найбільшу зміну між сусідніми елементами.

## Контейнер і умова варіанта
Використовується `std::array<int, 100>`. Для варіанта 11 потрібно знайти найбільший модуль різниці між сусідніми температурами `|tᵢ - tᵢ₋₁|` і номер пізнішого дня. Якщо найбільші зміни однакові, обирається перша пара.

## Псевдокод
1. Зчитувати цілі температури до `999` або кінця вводу.
2. Перевіряти коректність цілого числа, діапазон -100…100 і місткість масиву.
3. Якщо показів немає — вивести `No data`.
4. Для `i` від 1 до `n-1` обчислити модуль різниці сусідніх температур.
5. Оновлювати максимум лише при строгому збільшенні, щоб зберегти першу пару при рівності.
6. Вивести максимальну зміну та номер пізнішого дня.

## Ручний розрахунок тесту 1
Ввід: `-10 -5 8 8 -20 15 10 999`.
Модулі змін:
- день 2: `|-5 - (-10)| = 5`;
- день 3: `|8 - (-5)| = 13`;
- день 4: `|8 - 8| = 0`;
- день 5: `|-20 - 8| = 28`;
- день 6: `|15 - (-20)| = 35`;
- день 7: `|10 - 15| = 5`.
Отже, максимум дорівнює 35 °C, пізніший день — 6.

## Перевірки

| Ввід | Очікуваний результат | Фактичний результат |
|---|---|---|
| `-10 -5 8 8 -20 15 10 999` | `max change = 35 (day 6)` | `max change = 35 (day 6)` |
| `5 999` | `No pairs` | `No pairs` |
| `999` | `No data` | `No data` |
| `-2 -2 -2 -2 999` | `max change = 0 (day 2)` | `max change = 0 (day 2)` |
| `5 abc 999` | `Error`, код 1 | `Error: invalid integer`, код 1 |
| `5 101 999` | `Error`, код 1 | `Error: temperature out of range`, код 1 |
| 101 показ | `Error`, код 1 | `Error: too many readings`, код 1 |
| `1 5.5 999` | `Error`, код 1 | `Error: invalid integer`, код 1 |

## Висновок
Створено програму для пошуку найбільшої зміни температури між сусідніми днями. Використано `std::array`, перевірку введення та цикл із вибором першої пари у випадку однакових максимумів.
