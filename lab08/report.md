# Звіт до лабораторної роботи №08

**Тема:** Табулювання функції двох змінних (вкладені цикли)  
**Виконав:** Шумило Назар  
**Група:** 21КІ  
**Варіант:** 11

## Мета
Навчитися табулювати функцію двох змінних за допомогою вкладених циклів.

## Формула та область визначення
Для варіанта 11:
\[
z(x,y)=\sqrt{x-y}.
\]
Функція визначена за умови `x - y ≥ 0`. Значення `x` і `y`: від -1 до 1 з кроком 0.5. Рядки таблиці відповідають `x`, стовпці — `y`.

## Псевдокод
1. Надрукувати заголовок зі значеннями `y`.
2. Для кожного `x` від -1 до 1 з кроком 0.5:
   - надрукувати `x`;
   - для кожного `y` від -1 до 1:
     - якщо `x - y ≥ 0`, обчислити квадратний корінь;
     - інакше надрукувати `undefined`.

## Контрольні значення
- `f(-1, -1) = sqrt(0) = 0`;
- `f(0, 0) = sqrt(0) = 0`;
- `f(1, 1) = sqrt(0) = 0`;
- додаткова перевірка: `f(1, 0) = sqrt(1) = 1`.

## Трасування переходу між рядками
- Після завершення рядка `x = -1` зовнішній цикл переходить до `x = -0.5`.
- Після завершення рядка `x = -0.5` зовнішній цикл переходить до `x = 0`.
- Після завершення рядка `x = 0` зовнішній цикл переходить до `x = 0.5`.

## Перевірка
Матриця містить 5 рядків і 5 стовпців. Значення, для яких `x < y`, позначаються `undefined`; для інших обчислюється `sqrt(x-y)`. Контрольні точки мають значення 0, 0, 0 та 1 відповідно.

## Компіляція
Компілятор: g++  
Стандарт: C++17  
Команда: `g++ -std=c++17 -Wall -Wextra -pedantic task1.cpp -o task1`

## Висновок
Створено програму табулювання функції двох змінних із використанням вкладених циклів. Перед обчисленням квадратного кореня перевіряється область визначення, тому для недопустимих аргументів виводиться `undefined`.
