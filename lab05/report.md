### Мета роботи
Навчитися будувати таблицю значень функції однієї змінної за допомогою циклу `for`, перевіряти область визначення функції та форматувати результати виведення.

### Завдання
Для варіанта 11 задано функцію:

\[
y(x) = \frac{\sin(x)}{x - 0.5}
\]

Параметри: `a = -2`, `b = 2`, `h = 0.5`. Необхідно вивести 9 рядків для аргументів від −2 до 2 включно з кроком 0.5. Значення `sin(x)` обчислюється в радіанах.

### Псевдокод
1. Задати константи `a = -2`, `h = 0.5` і кількість рядків `9`.
2. Налаштувати виведення чотирьох знаків після коми.
3. Для `i` від 0 до 8 обчислити `x = a + i * h`.
4. Обчислити знаменник `x - 0.5`.
5. Якщо знаменник дорівнює нулю, вивести `undefined`.
6. Інакше обчислити `sin(x) / (x - 0.5)` і вивести результат.
7. Завершити програму.

### Результати роботи програми

| i | x | y |
|---:|---:|---:|
| 0 | -2.0 | 0.3637 |
| 1 | -1.5 | 0.4987 |
| 2 | -1.0 | 0.5610 |
| 3 | -0.5 | 0.4794 |
| 4 | 0.0 | 0.0000 |
| 5 | 0.5 | undefined |
| 6 | 1.0 | 1.6829 |
| 7 | 1.5 | 0.9975 |
| 8 | 2.0 | 0.6062 |

### Перевірка області визначення
Знаменник не повинен дорівнювати нулю:

\[
x - 0.5 \ne 0 \Rightarrow x \ne 0.5
\]

Тому для `x = 0.5` функція не визначена, і програма виводить `undefined`. Для решти заданих аргументів знаменник не дорівнює нулю.

### Трасування
**Допустимий аргумент `x = -2`:**

\[
y = \frac{\sin(-2)}{-2 - 0.5}
= \frac{-0.9092974}{-2.5}
\approx 0.3637
\]

**Недопустимий аргумент `x = 0.5`:**

\[
x - 0.5 = 0
\]

Ділення на нуль не виконується; програма виводить `undefined`.

### Контрольні обчислення
- Для `x = -2`: `y ≈ 0.3637`.
- Для `x = 0`: `y = sin(0) / (-0.5) = 0.0000`.
- Для `x = 2`: `y ≈ 0.6062`.
