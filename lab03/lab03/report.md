## Завдання 1. Формули трикутника

### Постановка
За трьома сторонами трикутника `a`, `b`, `c` обчислити:
- півпериметр: `p = (a + b + c) / 2`;
- площу за формулою Герона: `S = sqrt(p(p-a)(p-b)(p-c))`;
- радіус вписаного кола: `r = S / p`;
- радіус описаного кола: `R = abc / (4S)`;
- висоту до сторони `a`: `h = 2S / a`.

Вхідні значення мають бути додатними сторонами невиродженого трикутника.

### Псевдокод
```text
Ввести a, b, c
p = (a + b + c) / 2
S = sqrt(p * (p-a) * (p-b) * (p-c))
r = S / p
R = a*b*c / (4*S)
h = 2*S / a
Вивести p, S, r, R, h з двома знаками після коми
```

### Тести
| a | b | c | Очікуваний результат |
|---:|---:|---:|---|
| 3 | 4 | 5 | p=6.00; S=6.00; r=1.00; R=2.50; h=4.00 |
| 5 | 5 | 6 | p=8.00; S=12.00; r=1.50; R=3.13; h=4.80 |
| 1 | 1 | 1 | p=1.50; S=0.43; r=0.29; R=0.58; h=0.87 |

## Завдання 2. Складні відсотки, варіант 11

### Постановка
Обчислити суму вкладу через `n` років за формулою:

`s = p * (1 + r/100)^n`

де `p` — початкова сума, `r` — річна ставка у відсотках, `n` — кількість років.

### Обмеження
Початкова сума має бути невід'ємною, ставка — такою, щоб основа степеня була невід'ємною; кількість років — невід'ємною. У контрольному прикладі всі значення додатні.

### Псевдокод
```text
Ввести p, r, n
factor = 1 + r / 100
amount = p * pow(factor, n)
Вивести p, r, n та amount з чотирма знаками після коми
```

### Тести
| p | r (%) | n | Очікуваний результат |
|---:|---:|---:|---:|
| 1000 | 7.5 | 5 | 1435.6293 |
| 1000 | 0 | 5 | 1000.0000 |
| 1000 | 7.5 | 0 | 1000.0000 |
| 2000 | 5 | 2 | 2205.0000 |

## Завдання 3. Цифри чотиризначного числа, варіант 11

### Постановка
Для чотиризначного числа визначити суму та добуток його цифр, а також число, записане у зворотному порядку. Для виділення цифр використовуються операції цілочисельного ділення `/` та остачі `%`.

### Псевдокод
```text
Ввести чотиризначне число n
d1 = n / 1000
d2 = (n / 100) % 10
d3 = (n / 10) % 10
d4 = n % 10
sum = d1 + d2 + d3 + d4
product = d1 * d2 * d3 * d4
reversed = d4*1000 + d3*100 + d2*10 + d1
Вивести sum, product, reversed
```

### Тести
| Вхід | Сума цифр | Добуток цифр | Зворотне число |
|---:|---:|---:|---:|
| 4720 | 13 | 0 | 274 |
| 1234 | 10 | 24 | 4321 |
| 1000 | 1 | 0 | 1 |

У прикладі `4720` зворотне число математично дорівнює `0274`, але як ціле число воно виводиться як `274`.
