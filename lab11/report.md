# Звіт до лабораторної роботи №11

**Тема:** Утворення масивів, лінійний та бінарний пошук  
**Виконав:** Шумило Назар  
**Група:** 21КІ  
**Варіант:** 11

## Мета
Навчитися створювати масиви, виконувати відбір і зміну елементів, а також застосовувати лінійний і бінарний пошук.

## Умова варіанта
- Умова відбору: `0 ≤ t ≤ 20`.
- Операція: ущільнення — видалити всі температури `t < 0` або `t > 20`.
- Формула шкали: `scale[i] = i * i - 30`, `i = 0…11`.
- Місткість журналу: `kCapacity = 11`; розмір шкали: `kScaleSize = 12`.

## Псевдокод
1. Зчитати `n`, `n` температур і ключ `K`, перевіряючи межі.
2. Сформувати масив `selected` з температур у межах 0…20.
3. Ущільнити початковий масив, залишивши лише температури 0…20.
4. Виконати лінійний пошук першого входження `K`.
5. Побудувати шкалу за формулою та перевірити її зростання.
6. Виконати бінарний пошук `K` у шкалі й порахувати перевірені середні елементи.

## Ручний розрахунок тесту 1
Ввід: `7 -3 5 0 12 8 -1 7 12`.
Перші сім чисел після `n` — температури: `-3, 5, 0, 12, 8, -1, 7`; ключ `K = 12`.
- Відібрані значення: `5, 0, 12, 8, 7`.
- Після ущільнення журнал: `5, 0, 12, 8, 7`.
- Лінійний пошук: індекси 0, 1, 2; знайдено `12` за 3 порівняння, індекс 2.
- Шкала: `-30, -29, -26, -21, -14, -5, 6, 19, 34, 51, 70, 91`.
- Бінарний пошук для `12`: `mid=5` (значення -5), `mid=8` (34), `mid=6` (6), `mid=7` (19); ключа немає, 4 кроки.
