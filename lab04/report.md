## Завдання 1. Квадратне рівняння

### Постановка
Ввести дійсні коефіцієнти `a`, `b`, `c` та розв'язати рівняння `ax² + bx + c = 0`.

### Усі гілки та особливі випадки
1. `a = 0`, `b = 0`, `c = 0` — будь-яке `x` є розв'язком.
2. `a = 0`, `b = 0`, `c != 0` — коренів немає.
3. `a = 0`, `b != 0` — лінійне рівняння, `x = -c/b`.
4. `a != 0`, `D < 0` — дійсних коренів немає.
5. `a != 0`, `D = 0` — один корінь.
6. `a != 0`, `D > 0` — два корені.

### Трасування для `a=1, b=-3, c=2`
| Крок | Значення / дія |
|---|---|
| Ввід | a=1, b=-3, c=2 |
| Перевірка a | a не дорівнює 0 |
| Дискримінант | D = (-3)² - 4·1·2 = 1 |
| Перевірка D | D > 0 |
| Корені | x1 = 1.0000, x2 = 2.0000 |

### Тести
| a | b | c | Очікуваний результат |
|---:|---:|---:|---|
| 1 | -3 | 2 | Два корені: 1.0000 і 2.0000 |
| 1 | 2 | 1 | Один корінь: -1.0000 |
| 1 | 0 | 1 | Дійсних коренів немає |
| 0 | 2 | -4 | Лінійний корінь: 2.0000 |
| 0 | 0 | 0 | Будь-яке x |
| 0 | 0 | 5 | Коренів немає |

## Завдання 2. Обчислення функції, варіант 11

### Постановка
Обчислити функцію:
- якщо `x < 1`: `y = x² + x + 1`;
- якщо `1 <= x <= 4`: `y = sqrt(4 - x)`;
- якщо `x > 4`: `y = 1 / (x - 5)`.

Перевірити коректність введення та область визначення обраної гілки.

### Псевдокод
```text
Ввести x
Якщо введення некоректне — повідомити про помилку
Якщо x < 1:
    branch = 1
    y = x*x + x + 1
Інакше якщо x <= 4:
    branch = 2
    перевірити 4-x >= 0
    y = sqrt(4-x)
Інакше:
    branch = 3
    якщо x дорівнює 5 — повідомити про ділення на нуль
    y = 1/(x-5)
Вивести x, номер гілки та y
```

### Трасувальна таблиця
| x | Перевірка / гілка | Обчислення | y |
|---:|---|---|---:|
| 0 | x < 1, гілка 1 | 0² + 0 + 1 | 1.0000 |
| 2.5 | 1 <= x <= 4, гілка 2 | sqrt(4 - 2.5) | 1.2247 |
| 5.5 | x > 4, гілка 3 | 1 / (5.5 - 5) | 2.0000 |

### Тести, включно з межами
| x | Очікуваний результат | Яку гілку перевіряє |
|---:|---|---|
| 0 | 1.0000 | 1 |
| 1 | 1.7321 | 2, ліва межа |
| 2.5 | 1.2247 | 2 |
| 4 | 0.0000 | 2, права межа |
| 4.5 | -2.0000 | 3 |
| 5 | Помилка: ділення на нуль | 3, особливий випадок |
| 5.5 | 2.0000 | 3 |

Без перевірки при `x = 5` третя формула призвела б до ділення на нуль. Тому програма виводить повідомлення про помилку та завершується з кодом 1.

## Завдання 3. Переведення одиниць довжини через switch, варіант 11

### Постановка
Ввести код одиниці та довжину. Перевести значення в метри:
- 1 — міліметри, множник 0.001;
- 2 — сантиметри, множник 0.01;
- 3 — метри, множник 1;
- 4 — кілометри, множник 1000;
- 5 — дюйми, множник 0.0254;
- 6 — милі, множник 1609.344.

### Псевдокод
```text
Ввести код одиниці та довжину
Перевірити введення і невід'ємність довжини
За допомогою switch вибрати множник:
    1 -> 0.001
    2 -> 0.01
    3 -> 1
    4 -> 1000
    5 -> 0.0254
    6 -> 1609.344
    інакше -> помилка
метри = довжина * множник
Вивести результат у метрах
```

### Тести
| Код | Довжина | Очікуваний результат |
|---:|---:|---|
| 1 | 1000 | 1.000000 m |
| 2 | 100 | 1.000000 m |
| 3 | 10 | 10.000000 m |
| 4 | 2 | 2000.000000 m |
| 5 | 10 | 0.254000 m |
| 6 | 1 | 1609.344000 m |
| 7 | 10 | Помилка: некоректний код |
